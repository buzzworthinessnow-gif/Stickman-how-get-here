# Stickman How Did We Get Here?

A customized VideoExpress workflow for narrated 2D stickman history and explainer videos.

**Default runtime: 3–5 minutes** (aim for about 4 minutes).

See [SYSTEM_PROMPT.md](SYSTEM_PROMPT.md) for the production workflow, story structure, continuity rules, narration, assembly, and runtime checks.

This repository is separate from the upstream [videoexpress-stickman-story-agent](https://github.com/ai-playbooks/videoexpress-stickman-story-agent). Keep changes in this repository; do not modify upstream.
